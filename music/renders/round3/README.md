# Round 3 drafts: aggressive EDM rework

User notes on round 2: stage 1, the boss theme and both Flatwoods songs felt out of place; go more
aggressive EDM. Composed in `tools/music/edm.py`; the other six round 2 themes are unchanged.

| File | Title | Where it plays | Style |
|---|---|---|---|
| stage.mp3 | Overdrive | Mission 1 Rimeveil Lane | F minor electro, 150 BPM, reese bass |
| boss.mp3 | Hard Target | Every mid-boss + Space Kraken | D minor hard dance, 179 BPM |
| stage5.mp3 | Signal Lost | Mission 5 Flatwoods Drift | C minor acid house, 128 BPM, whole-tone UFO builds |
| flatwoods.mp3 | Braxton Breach | Flatwoods Monster | Bb minor hard dance, 179 BPM, siren breaks, whole-tone runs |

All four: sidechain-style pumping chords (rising envelope retriggered on each kick), bass that ducks
under the kick, snare-roll builds with a riser and a gap, four-on-the-floor drops with clap and
off-beat open hats. Each quotes the title hook.

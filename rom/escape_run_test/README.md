# Escape Run test builds (branch `escape-run`, Demo v1.2 work in progress)

- `sneaky_kryptid_escape_run.gbc`: the full game with mission 6. It unlocks after Flatwoods Drift.
- `sneaky_kryptid_escape_run_unlocked.gbc`: same, with every mission selectable from the start
  (title shows DEMO V1.2 UNLOCKED). Pick mission 6 on the map; SELECT+A starts at the dive.

Both are MBC5 + RAM + battery and upgrade an existing v1.0 / v1.1 save on first boot (save version 4).
The released ROMs in `rom/` are still Demo v1.1.

Things to watch on real hardware: the raster split under the flagship (and with the crew box
open above it), laser columns appearing and clearing, and the haze fade at the end of the dive.
